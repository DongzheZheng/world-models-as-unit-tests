Active observation

1. Observe

The agent spends a few real trials watching and probing the system. On the drone it hovered for a whole trial to log the other aircraft. On the pushing task it made two scripted pushes to locate the block’s centre of mass.

Hidden dynamics

2. Write the world model

It writes what it saw as one Python file of 14 to 26 KB. Physics the manual does not mention, such as a weak rotor or a shifted centre of mass, becomes named parameters estimated from the trials.

Random variation

3. Run the tests

Every candidate program runs in the world model before any further real trial, over many random episodes and several perturbed copies of the model. For 15 pushing programs, 3,000 simulated episodes took 19 s.

Test-time compute

4. Deploy, or test while acting

The version that passes goes to the real system. On the rope task the tests run during the episode. Every 0.16 s the controller tests candidate throws in the world model and executes the best one.
